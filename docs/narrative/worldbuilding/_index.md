# 世界观

## World Overview

旧文明在星际战争中灭绝，七座巨构以「死寂屏蔽」把地球伪装成死星。数万年后地表重新演化出新人类与兽人，
对旧文明、外星人与巨构一无所知。屏蔽正在裂开，沉默之塔孕育出数万年来第一个纯种旧人类——故事从这里开始。
