## 命名法

本世界的**地名全部是新人类自己的命名**，但按现实世界各地区的**神话典故**取材——大陆取"彼岸乐土"，国家取"神话领域"，城市取"神话城市 / 圣地"，无人区取"神话中的极端之地"。这样做的目的是：让读者一眼认出区域的文化底色，同时保持设定内命名的一致与辨识度。

> 每个区域对应一个现实神话文化圈，但允许跨圈借用。
> - **西陆 阿瓦隆** = 欧洲系（希腊 / 北欧 / 凯尔特 / 腓尼基）
> - **东陆 蓬莱** = 亚洲系（中国 / 日本 / 朝鲜 / 印度 / 波斯 / 两河 / 东南亚）
> - **南陆 阿兹特兰** = 美洲 / 非洲 / 大洋洲系（阿兹特克 / 玛雅 / 印加 / 埃及 / 西非 / 波利尼西亚）

## 一、世界概貌

- **星球**：一颗类地行星，海洋约占七成，气候带与季节与现实世界相近
- **陆地**：三块主要陆地 + 若干岛屿
- **地形谱**：极地冰盖 · 温带平原 · 亚热带丘陵 · 赤道雨林 · 干旱沙漠 · 深海海沟 · 高原
- **认知**：新人类的地理学与现代地球科学水平相当，但**没有旧文明留下的任何记录**——他们不知道脚下埋着什么

## 四、舞台国家：米德加德（Midgard）

**故事的主要发生地。**

| 项目 | 内容 |
| --- | --- |
| 名称 | 米德加德（北欧神话的"中庭"——人类居住的领域） |
| 位置 | 西陆，临埃律西昂内海，背靠山脉 |
| 国力 | **中等强国**——现代、开放，同时保有强力管制机构 |
| 政体 | **混合制**——形式民主，实际由少数集团主导 |
| 异力政策 | **登记管制型**，异力管制局总部所在 |
| 一句话定位 | "人类与兽人共同的中庭"——本设定中品种共存最彻底的样本 |

> 选择"中等强国 + 混合制"的理由：既足够现代与开放（撑得起媒体、学术、职业市场），又保留管制局式的强力机构；三种异力政策在其周边同时存在，便于展开国际张力。

## 七、产业带

产业分布同时受**地理**与**品种生理**影响（见 [races.md](../systems/races.md)）：

| 产业带 | 地理依托 | 人力特征 |
| --- | --- | --- |
| 重工业 / 采矿 / 建筑 | 矿区、内陆 | 力量型品种比例高 |
| 精密制造 / 医疗 / 电子 | 大都市圈 | 弱势型与常规型品种在精细岗位比例高 |

| 金融 / 媒体 / 科研 | 首都与大都市 | 混居，异力者就业集中 |

> **要点**：品种差异表现为**就业分布**，不是**等级**——力量型集中在重体力岗位，弱势型集中在精细岗位，都是市场选择而非制度安排。

## 八、人口

- **总量**：约 40 亿（远低于现实世界——无人区与低密度带占比极大）
- **品种结构**：人类与兽人混居，**无种族隔离**；跨品种通婚普遍
  - 城市品种更杂；乡村以家族为单位，品种更集中
- **异力者**：**极稀有**——占人口比例极小，是各国管制政策的成本基础
- **密度**：沿海与温带平原密集；沙漠、冰盖、高原、深海周边为**低密度或无人区**

## 十、国界、邻接与国际格局

**疆域原则**：国界大体**沿自然地理线**划分（山脉、河流、海岸、沙漠边缘），而非殖民式的直线——因为各国是**长期演化**而来，不是被划定的。

**米德加德的位置与邻接**（舞台国家）：

| 方向 | 邻国 | 关系 |
| --- | --- | --- |
| 北 | **卡美洛** | 同属登记管制型，**盟友**；君主立宪，王室与米德加德上层通婚 |
| 东（隔埃律西昂内海） | **亚特兰蒂斯** | 同属登记管制型，**竞争者**；海上贸易与金融的直接对手 |
| 南 | **塔拉** | 登记管制型，**中立**；王者之丘，宗教与学术传统深厚 |
| 西（边境） | **约顿海姆** | **军事征用型**，长期**对峙**——边境城市特洛伊即因此存在 |
| 海路 | **推罗同盟** | **放任市场型**；灰色贸易与"异力者避风港"，摩擦不断 |

**国际格局**：

- **条约体系**：存在一份 **《异力管制公约》**——登记管制型国家主导，确立"跨国异力犯罪引渡"与"禁咒清单"；**放任市场型与军事征用型均未签署**，这是最大的制度裂缝
- **协调机构**：**异力管制委员会**（松散常设机构，无常设武力，只有通报与协商权）
- **军力对比**：军事征用型国家（约顿海姆、昆仑、阿斯达、瓦尔、塔万廷苏尤、库施）军力最强；**核威慑仍是最上层级**；**没有正在进行的全面战争**，但存在**长期对峙**（约顿海姆 vs 米德加德、昆仑 vs 高天原）

**归入故事展开阶段**：各国具体节庆、民俗细节、地方制度差异。
