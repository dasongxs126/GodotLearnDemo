# 文案变更记录

本文件记录 `docs/narrative/` 文案体系的**版本里程碑**。

> **版本不依赖 Git tag**。本仓库同时承载 Godot 工程代码与文案，两条线演进节奏不同；tag 指向整仓库快照，会把代码状态卷进文案版本语义里。因此文案版本以**本文件 + README 顶部版本号**为准，每条里程碑绑定当时的 commit hash，回溯用 `git checkout <hash>`。

## 版本规则

- 版本号记在 [README.md](README.md) 顶部，与最新里程碑保持一致。
- **`vX.0`** = 阶段定稿（如"世界观定稿"）；**`vX.Y`** = 阶段内增量（新增或修订主题文件）。
- 提交信息统一用 **`docs(narrative): ...`** 前缀——文档历史可独立查看：
  ```bash
  git log --oneline -- docs/narrative/     # 文案独立历史
  git log --follow -- docs/narrative/world/magic.md   # 单文件历史
  ```
- 每条里程碑格式：`## vX.Y — 标题（日期）` + `commit: <短hash>` + 要点列表。

## v1.0 — 世界观定稿（2026-10-01）

commit: `64e53d2`

**主题**：确立科学奇幻基调，完成 ①科技基线 → ⑤社会·经济·文化 全链路搭建。

**要点**：

- **目录重构**：废弃物理版本目录 `docs/world/0.1.0/`，改为 `docs/narrative/`，按内容类型横向分类（world / characters / factions / story / quests / glossary）。
- **创作基调定案**：科学奇幻（Science Fantasy）+ 解释度三层——①有解（科技/巨构/外星物种/兽人遗传）/ ②半解（异力/残响）/ ③无解（空王座提问/认知污染深处/死寂之外）。两条硬规则：**同层解释度必须一致**；**②③层不需要科学解释**。
- **异力解释收口**：保留**来源**（普罗透斯基因 + 星骸种遗骸辐射）与**规律**（五系/稀有/可遗传/危险不稳定），**原理整块留白**（原"生命场/场共鸣结构"提案作废）。
- **第三套体系落地**：新增 [world/arts.md](world/arts.md) 术法体系——与异力**同源、同威力**，但**后天可学、极难**，修习者称"术士"。一句话：异力是天给的，术法是自己挣的。
- **一阶段核心冲突**：定为「**漏光**」——表层是异力/术法繁荣本身制造危险；里层是大规模施法泄漏生命波动、**从内部磨损死寂屏蔽**。
- **收口项**：威胁分级一至五级（微/常/危/灾/灭，异力与术法共用）；跨国通用语「通语」；跨国结算「金环」；宗教三会（承光教/砺火会/命纹会）；地理人口约 40 亿；国界、邻接与国际格局（《异力管制公约》、异力管制委员会）；宇宙两派自称（扩张派「纳者」/ 和平派「易者」）。
- **有意留白（不补）**：和平派下落（二阶段悬念）、反异力武器机制、异力与术法原理。

**状态**：世界观（①→⑤）全部定稿。`characters/`、`story/`、`quests/` 为旧版待重写，进入「故事展开」阶段后重建。
