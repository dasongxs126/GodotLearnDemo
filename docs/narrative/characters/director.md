| --- | --- |
| 身份 | 异力管制局现任局长 |
| 异力 | 时间系（极稀有） |
| 能力边界 | 回溯几分钟；预知数日内的概率碎片；在禁咒事故中看到断裂画面 |
| 认知层 | 知道碎片，不知道全貌 |
| 核心矛盾 | 知道遮蔽正在失效，却无法公开——公开本身会加速泄漏 |

**设定要点**：

- 他是全世界唯一触碰到真相边缘的人，但**能力太弱、证据太少**，说出去只会被当成疯子，或引发恐慌
- 他看到的碎片：天空之外的"眼睛"、正在裂开的"死寂"、地下七根巨大锚点、月光其实来自地下的反射
- 他看那个旧人类孩子时，莫名觉得那孩子与碎片里的"地下七柱"有关，却说不清为什么
- 他的困境：**知道得太多，又知道得太少**

**一阶段功能**：玩家 / 读者的"真相窗口"——所有作者层信息都通过他的碎片间接透露，且始终不完整。
