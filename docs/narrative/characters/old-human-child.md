| 身份 | 沉默之塔孕育的第一个纯种旧人类 |
| 年龄 | 婴儿（故事开端） |
| 基因 | 完全旧人类，无普罗透斯基因，无兽人分支 |
| 异力 | 天生不会异力（旧人类不会魔法） |
| 特殊 | 能激活巨构，能进入空王座，在梦中被空王座召唤 |
| 认知层 | 什么都不知道 |

**设定要点**：

- 由沉默之塔在数万年后第一次启动孕育程序诞生
- 出生时"不属于任何家族"——在同一天夜里，另一个普通家庭也迎来了一个人类孩子（父人类 / 母兽人）
- 被异力管制局视为"异常个体"关注
- 被局长在时间碎片中隐约感到与"地下七柱"有关，却拼不出缘由

**故事开端原文**：

> 一个人类父亲与兽人母亲生下人类孩子——这很普通。
> 但同一个夜晚，沉默之塔深处，一个不属于任何家族的婴儿睁开了眼。
> 他的基因里没有普罗透斯人，没有兽人，没有新人类的痕迹。
> 他是旧人类。
> 他是数万年来第一个纯种旧人类。
> 而他自己，什么都不知道。
