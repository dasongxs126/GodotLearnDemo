## 一、关键角色

### 1.1 异力管制局局长

| 项目 | 内容 |
| --- | --- |
| 身份 | 异力管制局现任局长 |
| 异力 | 时间系（极稀有） |
| 能力边界 | 回溯几分钟；预知数日内的概率碎片；在禁咒事故中看到断裂画面 |
| 认知层 | 知道碎片，不知道全貌 |
| 核心矛盾 | 知道遮蔽正在失效，却无法公开——公开本身会加速泄漏 |

**设定要点**：

- 他是全世界唯一触碰到真相边缘的人，但**能力太弱、证据太少**，说出去只会被当成疯子，或引发恐慌
- 他看到的碎片：天空之外的"眼睛"、正在裂开的"死寂"、地下七根巨大锚点、月光其实来自地下的反射
- 他看那个旧人类孩子时，莫名觉得那孩子与碎片里的"地下七柱"有关，却说不清为什么
- 他的困境：**知道得太多，又知道得太少**

**一阶段功能**：玩家 / 读者的"真相窗口"——所有作者层信息都通过他的碎片间接透露，且始终不完整。

---

### 1.2 纯种旧人类（故事开端）

| 项目 | 内容 |
| --- | --- |
| 身份 | 沉默之塔孕育的第一个纯种旧人类 |
| 年龄 | 婴儿（故事开端） |
| 基因 | 完全旧人类，无普罗透斯基因，无兽人分支 |
| 异力 | 天生不会异力（旧人类不会魔法） |
| 特殊 | 能激活巨构，能进入空王座，在梦中被空王座召唤 |
| 认知层 | 什么都不知道 |

**设定要点**：

- 由沉默之塔在数万年后第一次启动孕育程序诞生
- 出生时"不属于任何家族"——在同一天夜里，另一个普通家庭也迎来了一个人类孩子（父人类 / 母兽人）
- 被异力管制局视为"异常个体"关注
- 被局长在时间碎片中隐约感到与"地下七柱"有关，却拼不出缘由

**故事开端原文**：

> 一个人类父亲与兽人母亲生下人类孩子——这很普通。
> 但同一个夜晚，沉默之塔深处，一个不属于任何家族的婴儿睁开了眼。
> 他的基因里没有普罗透斯人，没有兽人，没有新人类的痕迹。
> 他是旧人类。
> 他是数万年来第一个纯种旧人类。
> 而他自己，什么都不知道。
