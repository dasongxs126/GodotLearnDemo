# 文风设定

本书的文风决策，按文字编辑的方式记录；起草或修订正文前先读。`story prose` 按 frontmatter 的清单检查：`dialect`（british / american / unspecified）标出另一种拼写的常用词；每条 `preferred` 标出对应的 `avoid` 写法；`watch-words` 在每章统计出现次数；`allow-words` 用于放行被内置过滤的词或副词。把已定稿章节加入 `samples` 后，`story prose` 会用它们对比当前章节，而不是套固定上限。

## 术语表约定

**认知层**列说明该术语在世界观内属于哪一层知识：`公开` = 新人类普遍知道；`作者层` = 只有作者 / 局长碎片知道。

## 命名规则提醒

- 新人类**不知道**外星人、巨构、异力来源，因此所有公开层术语必须是**本地化、经验化、迷信化**的，禁止出现"星骸""七柱"这类宏大命名。
- "异力"一词本身就是新人类因不了解而起的模糊称呼，属于正确的公开层命名。
- **巨构的七个名称（沉默之塔、永绿之园、月猎神庙、低语陵、火炬残像、迷雾灯塔、空王座）是作者层命名，禁止出现在公开层文案中。** 新人类不知道这些名字，也不知道巨构的存在，更不知道有任何与之相关的现象。
