# 文案文档索引

本目录存放《死寂之下》的全部文案类文档（世界观、角色、势力、剧情、任务、术语）。

## 组织原则

1. **按内容类型横向分类，按主题纵向拆文件**：一个主题一个文件，避免单个文档无限膨胀。
2. **版本由 Git 管理**：不使用 `0.1.0/` 之类的物理版本目录。历史版本用 `git log` / `git diff` 查阅，快照用 tag 或 `archive/` 目录。
3. **认知分层贯穿全文**：所有设定必须标注属于哪一层认知，禁止把作者层真相泄漏进新人类可感知的内容。
   - **作者层真相**：完整真相（旧文明、外星人、巨构、死寂屏蔽）
   - **新人类认知**：不知道旧文明、外星人、巨构、死寂屏蔽
   - **异力管制局认知**：只当自己是管异力者的治安机关
   - **局长个人认知**：因时间系能力窥见碎片，但拼不出全貌
4. **命名约定**：目录名小写英文，文件名小写英文、`snake_case`；正文中文，专有名词保留设定原名。
5. **巨构完全不可知**：七座巨构本体全部深埋在无人区，**不产生任何可观测现象**。新人类从未见过它们，也没有任何与之相关的传说、地名或信仰。因此不存在守护、继承或世代侍奉巨构的角色，也不需要为巨构设计任何影响新人类的钩子。

## 创作基调：科学奇幻

**基调 = 科学奇幻（Science Fantasy）**：世界规则可解释，但**刻意保留"解释不了的那部分"**——那是魔法与神秘的来源，不是漏洞。

**解释度三层**（任何设定先归类，**同层解释度必须一致**）：

| 层 | 解释度 | 内容 | 作用 |
| --- | --- | --- | --- |
| ① 有解 | 完整机制 | 科技、巨构原理、外星物种、兽人遗传 | 可信感——让世界立得住 |
| ② 半解 | 机制可解，**本质留白** | 异力、残响 | 魔法感——有规律，却永远差最后一层 |
| ③ 无解 | **作者层也留白** | 空王座的提问、认知污染的深处、死寂之外 | 神秘感——敬畏与悬念 |

**两条硬规则**：

1. **同层一致**：新元素先归入某一层，其解释度必须与该层其他元素一致。忽而全解释、忽而全不解释，才是"显得奇怪"的真正原因——**让人觉得奇怪的从来不是"没解释"，而是"解释度不一致"**。
2. **②③层不需要科学解释**：这个世界本身就承认"有不可解释之物"——这正是"科学与信仰张力"（见 [world/technology.md](world/technology.md)）的根基。想加奇幻元素，放进②或③即可，不必强行科学化。

> **比例可调**：想要奇幻感更重，就把更多元素划进②③，而**不是**把①层挖空——①层的厚度是世界可信度的地基。

> **元素可以跨层**：同一个元素的**不同侧面**可以落在不同层。例：**异力**——**来源**（普罗透斯基因）与**规律**（五系、稀有、可遗传、危险不稳定）属于①/②层，而**原理**（为什么能这样运作）整块留白、属③层。所以"异力要不要科学解释"的精确答案是：**来源和规律要，原理不要**。
