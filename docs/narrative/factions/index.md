# 主要势力

> **认知层**：新人类层面为公开认知；宇宙层面为作者层（新人类完全不知道）。

---

## 一、新人类层面

**现代社会架构下的势力**（对照 [society.md](../world/society.md)、[polity.md](../world/polity.md)）：

| 势力 | 性质 | 目标 |
| --- | --- | --- |
| **异力管制局** | 国家机构 | 登记异力者与术士、封锁异常区域、维护秩序 |
| **军工与反异力企业** | 跨国资本 | 反异力武器、异力与术法服务市场、利润 |
| **媒体集团** | 传媒 | 流量与舆论——异力议题的放大器 |
| **宗教与新兴教派** | 信仰组织 | 解释异力与术法（神赐 / 试炼 / 诅咒 / 修行） |
| **异力者行会 / 术法行会** | 职业组织 | 异力者与术士的权益、许可与职业责任险 |
| **跨品种家族网络** | 社会联结 | 跨品种家族与行会的横向网络 |
| **政党与政治家族** | 政治组织 | 登记政策的博弈 |
| **边境与地下势力** | 灰色组织 | 走私、无证异力者、逃避登记 |

### 关键张力

- **异力管制局 vs 异力者行会**：一方要登记，一方要权利——围绕"登记天生特征"的争论（见 [magic_regulation.md](../world/magic_regulation.md)）
- **军工企业 vs 人权舆论**：异力越受重视，反异力装备越赚钱——一个自洽的产业悖论
- **媒体**：异力议题高流量、高对立，既是监督者也是放大器
- **宗教**：为"科学解释不了"的异力与术法提供意义
- **异力者 vs 术士**：天赋与苦修的对立——"力量该不该被赐予"的长期争论（见 [arts.md](../world/arts.md)）
- **巨构没有任何守护者或继承者**：旧人类已灭绝，新人类是独立演化而来，不存在世代侍奉巨构的组织，也不存在掌握巨构知识的角色
- 所有势力对世界的理解都停留在**自身经验层面**，没有任何一方掌握作者层真相

## 二、宇宙层面

**全部为作者层。** 新人类完全不知道外星文明的存在。势力明细见 [../world/aliens.md](../world/aliens.md)。

| 势力 | 性质 | 目标 |
| --- | --- | --- |
| 星骸种（扩张派残余） | 收割型 | 上瘾于旧人类残响；确认地球重新有生命后再次入侵 |
| 造访者残部（和平派） | 探索型 | 等待地球信号，可能成为盟友 |
| 收割者联盟 | 松散联盟 | 如果星骸种无法独吞，介入分食 |
| 静默议会 | 古老文明联合体 | 封锁太阳系，防止星骸种扩散 |
| 深空游牧者 | 拾荒文明 | 掠夺七柱技术，或出售地球坐标 |
