# 术法体系

> **认知层**：术法的**存在、规则、社会地位**为**公开认知**；"来源真相"为**作者层**。
>
> 术法是本世界的**第二套魔法体系**，与 [异力](magic.md) **同源、同威力**，区别只在**获得方式**。

---

## 一、定义

**术法**——新人类**后天摸索**出来的一套魔法体系。修习者称**术士**。

- **来源真相**（作者层）：与异力**同源**——都建立在**外星残骸造成的"魔力土壤"**之上（见 [aliens.md](aliens.md) §5.1）。外星残骸是**条件，不是蓝图**：新人类没有抄任何东西，是在这片土壤上**自己走出了一条路**。
- **民间认知**（公开层）：术法是人类**世代相传的技艺**——祖师、门派、秘传、口授心传。**没有人知道它和异力其实同源。**
- **官方口径**：与异力**同列**，纳入同一套登记与管理（见 [magic_regulation.md](magic_regulation.md)）。

---

## 二、术法与异力：同源，两条路

| | **异力** | **术法** |
| --- | --- | --- |
| 来源 | 外星残骸（**同源**） | 外星残骸（**同源**） |
| 获得 | **天生** · 不可选 | **后天** · 可学，极难 |
| 威力 | **同等** | **同等** |
| 性质 | 天赋——不劳而获 | 苦修——自己挣的 |
| 施法方式 | 本能即可 | 需**仪式 / 媒介 / 长期训练** |
| 俗称 | **法师** | **术士** |

> **一句话**：**异力是天给的，术法是自己挣的。同源、同威力，只是入场方式不同。**

**对普通人而言，两者几乎没区别**——在街头巷尾，异力者与术士都是"会施法的人"。真正的分野只有圈内人（管制局、行会、研究者）才在意。

---

## 三、学习：可学，但极难

- **理论上人人可学**——术法不挑血脉、不挑品种
- **但极难**：绝大多数人穷其一生也摸不到门槛
- **靠师承**：门派、行会、私塾式口授心传；**没有教材能教出术士**
- **为什么这么难**（作者层）：术法与异力一样，**原理留白**（见 [../README.md](../README.md) 创作基调）——**可学、有规律，但"为什么有效"没人说得清**，因此只能靠师承与长期试错，**无法写成公式、无法工业化**

> 这解释了为什么科学**造得出装备、造不出术士**（见 [magic_regulation.md](magic_regulation.md) 反异力武器）。

---

## 四、术法的"系"

术法与异力**共用同一套"系"分类**（生命 / 元素 / 精神 / 空间 / 时间）——因为"系"是**效果分类**，不是来源分类（见 [magic.md](magic.md) §二）。

> 差别只在**怎么使出来**：异力者本能调动，术士靠仪式与媒介。

---

## 五、危险性

与异力完全相同：

- 大规模施法会**泄漏生命波动**，可能招来"天外之眼"（见 [magic.md](magic.md) §三）
- 禁咒可能诱发**认知污染**

---

## 六、社会地位

- **与异力同等，且同样要登记**——这是本世界最没有争议的共识之一：**两条路都通向同一种危险，就必须接受同一套管理**（见 [magic_regulation.md](magic_regulation.md)）
- **行会与师承**：术法有自己的组织形态——门派、行会、学院，比异力者的"个人登记"更**集体化**
- **职业化**：与异力者一样进入劳动市场（医疗、工程、安保、救援）
- **阶层**：高等术士与高等异力者同处社会上层（见 [society.md](society.md)）
- **同为登记，政治含义不同**：异力者的登记理由是"**天生的、不可选的**"，术士的登记理由是"**习得的、有组织的**"——前者是"监视天赋"，后者是"牌照管理"

---

## 七、流派、门槛与等级

**流派与传承**：术法**不按"系"分派，而按"传承"分派**——各大陆各有传统：

| 大陆 | 传统 | 特征 |
| --- | --- | --- |
| 西陆 阿瓦隆 | **符号与仪式** | 强调咒式、铭纹、祭仪；学院与行会传统 |
| 东陆 蓬莱 | **呼吸与内修** | 强调吐纳、冥想、身心一体；师门与秘传 |
| 南陆 阿兹特兰 | **自然与药引** | 强调草木、矿药、天时；部族与祭司传统 |

**门槛**：术法**无血脉门槛，但有"感知"门槛**——须能察觉那股力量。这种感知**可以培养，却无法强求**，所以大多数人穷其一生也摸不到门槛。

**等级**：与异力**共用一至五级**（见 [magic_regulation.md](magic_regulation.md)）；此外术士另有**师承位阶**：学徒 → 术士 → 大术士 → 宗师。

**行会与管制局**：**行会负责传承与自律，管制局负责登记与执法**——分工明确，偶有摩擦（行会嫌管制局不懂术法，管制局嫌行会包庇）。

**术士与异力者**：**表面互相尊重，私下互不服气**——异力者觉得术士"练一辈子也不如天生"，术士觉得异力者"不劳而获"。
