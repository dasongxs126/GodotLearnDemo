# 巨构

> **认知层**：本文件为**纯作者层**。
>
> 新人类不知道巨构的存在，也不知道"巨构"这个概念。巨构本体全部深埋在无人区，**没有任何可观测的副作用现象**——新人类对它们一无所知，也没有任何与之相关的传说、地名或信仰。
>
> **本文件内容禁止出现在任何面向新人类的内容中。**

---

## 一、总览

七座巨构，旧文明遗产，**七柱协议**的组成部分。战争后进入自动模式，维持死寂屏蔽，其中一座是基因火种库。

**七座巨构的本体全部不可见、不可及。** 战后它们被地质运动深埋在无人区——沙海之下、海沟之下、冰盖之下、地下数千米。它们既不泄漏能量，也不产生可观测的异常，因此**从未被新人类发现**。

新人类**从未见过任何一座巨构的本体，也从未意识到它们的存在**，甚至不知道"巨构"这个概念。

> **作者层补充**：七柱联网后原名**"万神屏障"**。它们既保护地球不被星骸种回归吞没，也维持死寂屏蔽。但识别标准仍是旧文明那套，所以偶尔会故障、误判、攻击高星骸浓度目标。

## 三、沉默之塔（基因火种库）

**作者层真相**：

- 保存旧人类基因、生态模板、文明种子
- 原始任务：等待地表环境恢复，孕育新人类，尽量按旧人类方式演化
- 普罗透斯人的基因残留渗入演化，出现兽人分支
- 一直在观察、微调、记录

**孕育能力**：

- 数万年来第一次启动孕育程序
- **原因**：死寂屏蔽将在数十年内失效，新人类没有旧文明知识、技术、基因认证，无法启动七柱协议
- 唯一办法：孕育一个纯种旧人类——一个拥有旧文明基因认证、能进入空王座、能重启七柱协议的人
- 这是最后一张牌

**故事开端**：

> 一个人类父亲与兽人母亲生下人类孩子——这很普通。
> 但同一个夜晚，沉默之塔深处，一个不属于任何家族的婴儿睁开了眼。
> 他的基因里没有普罗透斯人，没有兽人，没有新人类的痕迹。
> 他是旧人类。
> 他是数万年来第一个纯种旧人类。
> 而他自己，什么都不知道。

## 四、永绿之园（最后庇护所）

**作者层真相**：

- 旧文明战争打到后期，地表已不适合居住
- 大气被星骸残骸污染，水源带毒
- 旧文明把永绿之园改造成**最后的地表庇护所**，容纳了大量平民、工程师、基因样本和儿童
- **垂直城市**结构：
  - 底层：水循环与土壤修复
  - 中层：居住区、学校、医院
  - 上层：大气净化与播种系统
  - 顶层：旧文明最后议会厅与观测台
- 战后继续自动运行，慢慢被植被覆盖
- **地表之下，还埋着一座旧文明最后城市**

## 八、迷雾灯塔（死寂屏蔽主控）

**作者层真相**：

- 维度灯塔、防火墙、**死寂屏蔽主控**
- 标记安全航道，驱散星骸空间迷雾，阻止外星折跃
- 维持死寂屏蔽，使地球在宇宙尺度上不可见
- 一旦过载，屏蔽可能破裂

## 九、空王座（七柱指挥中枢）

### 9.1 作者层真相

七柱指挥中枢。统合所有巨构，控制行星护盾与最终程序。王座空置，需旧人类或造访者认证。

### 9.2 最终选择

如果有人坐上空王座，七柱协议会重新联网。空王座会提问：

| 选择 | 结果 |
| --- | --- |
| 净化 | 清除所有星骸基因，兽人可能消失 |
| 重启 | 按旧人类模板重新演化，新人类可能被替换 |
| 共生 | 让人类、兽人、星骸、造访者融合成新物种 |
| 复仇 | 启动七柱武器，向外星文明反击 |
| 沉默 | 维持死寂屏蔽，但这次把新人类自己也屏蔽 |

### 9.3 谁能坐上王座

- **纯种旧人类**：基因认证通过，天然拥有访问权限
- **造访者**：如果仍存在
- **人类与兽人的子代**：可能，但需要特殊条件
- **强行启动**：可能引发七柱防御机制
