## 一、物种：普罗透斯人

| 项目 | 内容 |
| --- | --- |
| 母星 | **普罗透斯（Proteus）**——两派共同的家园 |
| 形态 | **类人生物形态** |
| 天赋 | **吸收基因，演化自身**——接触生命、解析其基因、纳入自身基因库，并选择性地表达出来 |
| 现状 | 母星仍有扩张派残余；和平派下落不明 |

> 这项天赋是他们一切行为的根源，也是他们内部分裂的根源。

## 二、两派：同一物种，两种良心

**分歧不在形态，而在伦理**——"吸收"这件事该怎么做：

| | **扩张派 · 星骸种** | **和平派 · 造访者** |
| --- | --- | --- |
| 吸收方式 | **强制**：活体、非自愿、知情 | **资源交换尸体** |
| 获取 | 直接收割生命 | 用资源换取尸体，只取基因 |
| 附带 | 制造**残响**（武器原料） | 无意识、无抵抗、**无残响** |
| 对外 | 入侵、寄生、收割 | 共生、灵能沟通、空间折跃 |
| 争议 | 被和平派视为**谋杀 + 把死者当武器** | 被扩张派视为迂腐 |

> **命名说明**："星骸种""造访者"是**外界**给两派的称呼。他们**自称**——扩张派自称**「纳者」**（认为"吸收"是生命的天职），和平派自称**「易者」**（认为"交换"才是长久之道）。

## 三、残响：扩张派的武器（核心机制）

### 3.1 残响是什么

- 生命被**吸收**时，其意识不会干净地消失，会留下**印记** → **残响**
- 扩张派把残响**提炼**为**单一使用的武器**（生命电波武器）

### 3.2 威力取决于情感

> **残响的威力，依托于被吸收者当时的情感。**

- 情感越强（恐惧、愤怒、不甘）→ 残响越强 → 武器越强
- 无情感者 → 残响几乎无威力 → **废料**
- **推论**：扩张派偏爱情绪化的猎物，甚至会**故意折磨**受害者以激化情感、提高产量——**残忍是工艺要求**

### 3.3 旧人类：威力极大，但会反噬

- **旧人类的残响是威力极大的类型**——扩张派眼中的顶级原料
- **代价**：旧人类的**电波辐射太强**，会让吸收者**产生幻象**
- **扩张派的选择**：因为实在太强，**顶着副作用也坚持收割**

> 这解释了星骸种为什么反复扑向地球——他们不是想占领，是**上瘾**。

### 3.4 反制：旧人类屏蔽情感 → 断供

- 战争后期，旧人类用**科技手段屏蔽了情感**
- 结果：此后被吸收的旧人类残响**几乎没有威力**
- **扩张派的武器来源就此断裂**——这是战争的转折点，也是"同归于尽"得以发生的原因

## 四、认知污染

- 残响武器释放时的电波会干扰意识 → **低语、幻象、记忆错乱** = 认知污染
- 一般残响的电波可控（作为武器）
- **旧人类残响的电波过强，连持有者都中招**——即 3.3 的"幻象"
- 被旧人类残响逼疯的星骸领主，被封进 [低语陵](megastructures.md)

## 五、兽人真相：外星基因的隔代表达

| 步骤 | 内容 |
| --- | --- |
| ① 旧人类时期 | 普罗透斯人大量吸收地球生命细胞 |
| ② 基因库成形 | 其基因库保存了旧人类时期生命的完整蓝图 |
| ③ 战后残留 | 普罗透斯人的基因残留在生物圈，进入新人类演化阶段 |
| ④ 兽人分支 | 携带普罗透斯基因的新人类，天然能吸收生命基因并表达 → 兽人 |

**副产品**：

- 解释了兽人为何是**地球动物形态**（狼、鹰、蛇……）
- **父系显形律**可能是普罗透斯"表达规则"的残余
- 兽人从"污染受害者"变成"**继承天赋的分支**"

### 5.1 同源两支：兽人与异力

普罗透斯基因在新人类身上有**两条表达路径**，两者**同根**：

| 表达路径 | 结果 | 特征 |
| --- | --- | --- |
| **体细胞方向**（吸收生命基因、改写自身） | **兽人** | 稳定、可遗传（父系显形律） |
| **神经方向**（被星骸辐射诱导） | **异力者** | 稀有、不稳定 |

> **兽人把天赋用在自己身上，异力者把天赋用在身外**——同源于那份残留在生物圈里的普罗透斯基因。星骸辐射是异力的**诱导条件**（兽人不需要）。
>
> 异力**只给来源与规律，原理不解释**（见 [magic.md](magic.md)）。

## 六、和平派（造访者）

- 与扩张派**同母星系**，长期被其压制
- 能力：非攻击性灵能、空间折跃（需**灯塔坐标**）、共生技术
- 助地球 = **自救**（削弱扩张派就是保护自己）
- 战后下落**留白**（二阶段悬念）
