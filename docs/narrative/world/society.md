## 一、社会分层

**分层依据：职业 · 契约 · 家族 · 实力。品种不是分层依据。**

| 层级 | 构成 |
| --- | --- |
| **上层** | 政治家族、大资本、高等异力者、高等术士、管制局高层 |
| **中产** | 专业与技术阶层、常规异力者、术士、公务员、军官 |
| **劳动层** | 重体力、制造、服务、运输 |
| **边缘** | 边境居民、无证异力者、流动人口 |

**两条与品种 / 异力有关的张力**：

- **品种只影响就业分布，不影响阶层**——力量型品种（牛、虎、熊）在重体力岗位多，弱势型（兔、猫）在精细岗位多，但两类都横跨各阶层（见 [races.md](races.md)）
- **异力者是"新贵"也是"新焦虑"**——因稀有而获得高薪与地位，却因登记制度承受制度性审视（见 [magic_regulation.md](magic_regulation.md)）
- **术士是"另一条上升通道"**——不靠血脉、靠苦修；异力者是天生的少数，术士是**练出来的少数**。两者同处上层，却代表两种截然不同的价值观（见 [arts.md](arts.md)）

## 二、教育

- **基础教育**：全民义务，现代课程体系（与现实 2020 年代相当）
- **高等教育**：大学与研究机构；顶尖学府集中在大都市（如米德加德的亚历山大）
- **体育教育**：**按品种分组的竞技体系**——力量型与弱势型分级比赛，类似现实的分量级
- **异力教育**：异力者须接受**登记与分级培训**；评级决定其可从事的职业与可使用的异力强度
- **术法教育**：不走学校体系，走**师承**——门派、行会、私塾式口授心传；**没有教材能教出术士**（见 [arts.md](arts.md)）
- **两门"特殊学科"**：
  - **父系显形律研究**：能统计、能预测，**解释不了机制**
  - **异力学**：能测量强度、能分级，**找不到生理基础**

> 这两门学科是现代科学的"边缘"——它们存在、被严肃对待，却始终无法闭合。这养活了宗教、伪科学与阴谋论（见第五、六节）。

## 三、医疗

- **现代医学水平**：与现实 2020 年代相当
- **生命系异力者的医疗角色**：治疗、催生、变形——**合法职业化的异力应用**（需持证）
- **异力者的健康监管**：登记体检、异力强度评估、事故责任认定
- **品种生理差异**：医学按品种调整标准（如力量型品种的肌肉骨骼负荷、弱势型品种的代谢）
- **医疗不平等**：异力治疗昂贵，多集中于私立机构与大都市，引发"双轨医疗"争议

## 四、媒体

- **生态**：传统媒体（报纸、电视）+ 社交网络 + 全球新闻（与现实 2020 年代相当）
- **异力是永恒热点**：异力犯罪、异力者权益、登记争议——**高流量、高对立**
- **新闻自由因国而异**：代议制国家开放，集权制国家管控（见 [polity.md](polity.md)）
- **伪科学与阴谋论繁荣**：因为异力与父系显形律"观测得到、解释不了"
- **关键约束**：**没有与巨构相关的信息可供传播**——新人类不知道巨构存在，媒体自然也无从报道（见 [technology.md](technology.md)）

## 五、宗教与信仰

**为什么宗教繁荣**："科学解释不了的日常事实"（异力、术法、父系显形律）为信仰留出了空间。

| 类型 | 态度 |
| --- | --- |
| **承光教**（传统） | 视异力为**神赐之光**——需感恩与克制 |
| **砺火会**（传统） | 视异力为**试炼之火**——需苦修淬炼 |
| **命纹会**（新兴教派） | 视异力为**血脉神选**——围绕异力者建立崇拜 |
| 无神论 / 世俗主义 | 视异力为"待解的自然现象" |
| 异力者自身 | 信仰各异——有人自认神选，有人只想当普通人 |

> **对术法的态度**：承光教视其为"人自己求来的力量"，砺火会视其为"另一种淬炼"，命纹会贬其为"凡人的僭越"。
>
> **注意**：宗教解释的是**异力与术法**，不是巨构——新人类没有任何关于巨构的神话（见 [glossary.md](../glossary.md)）。

## 六、经济

- **货币**：各国自有货币；**跨国结算**通用 **「金环」**（以黄金与异力服务双重担保的记账单位）
- **市场**：现代金融体系、国际贸易、全球供应链（与现实 2020 年代相当）
- **异力者劳动市场**：分级许可 → 高薪职业（医疗、工程、安保、救援）；配套**职业责任险与事故赔偿**
- **反异力武器产业**：军工分支，各国采购——**异力越受重视，反异力装备越赚钱**（一个自洽的悖论）
- **产业与品种**：见 [geography.md](geography.md) 产业带
- **不平等**：异力者与大都市受益最多，边境与无人区被边缘化

## 七、文化

- **共生文化**：人类与兽人混居、跨品种通婚普遍、**无系统性歧视**
- **品种文化**：家族徽记、形态传承、节庆与饮食差异——**是文化多样性，不是等级**
- **体育**：品种差异在竞技中最直观（分级别），也是社会最"看得见"的品种话题
- **语言**：各国母语并存；**通语**为跨国通用语（源于西陆贸易，现用于学术、外交与商业）
- **日常张力**：真正被争论的不是"品种"，而是"**异力**"——登记、隐私、权利
- **"天赋 vs 苦修"的文化对立**：异力者（天生）与术士（后天）在公众眼里几乎无区别，但两个群体内部对"力量该不该被赐予"有长期争论（见 [arts.md](arts.md)）

- **通用语**：**通语**——源于西陆贸易，现为跨国通用语；各国母语并存，学术与外交多用通语
- **货币**：各国自有货币；跨国结算通用 **「金环」**
- **宗教**（选列）：**承光教** / **砺火会** / **命纹会**（见第五节）

**归入故事展开阶段**（世界观层面不再展开）：

- 教育制度细节（学制、考试、升学）
- 医疗保险与异力事故赔偿的具体机制
