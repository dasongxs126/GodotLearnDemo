- 战争打到地表不适合居住
- 建造七柱协议
- **用科技屏蔽情感，切断星骸种的残响武器来源**
- 与星骸种同归于尽
- **灭绝**

- 战争后进入自动模式
- 维持死寂屏蔽

- 识别标准失效，偶尔故障、误判、攻击高星骸浓度目标
- 联网后原名"万神屏障"

- 人类与兽人友好共生
- 父系显形（可能是普罗透斯"表达规则"的残余）

## 四、外星物种速查

### 普罗透斯人（母星：普罗透斯）

- 形态：**类人生物形态**
- 天赋：**吸收基因，演化自身**
- 因"吸收"的伦理分歧分为两派：

| 派系 | 吸收方式 | 立场 |
| --- | --- | --- |
| **扩张派 · 星骸种** | 强制活体吸收（非自愿、知情）→ 制造**残响** | 收割、入侵 |
| **和平派 · 造访者** | 资源交换**尸体**，只取基因 | 友好，站在地球方 |

### 残响（扩张派的武器）

- 生命被吸收时留下的意识印记 → 提炼为**单一使用的武器**
- **威力依托于情感**：情感越强，残响越强
- **旧人类残响威力极大**，但**电波辐射太强，会让吸收者产生幻象**；扩张派因它太强，**顶着副作用坚持收割**
- **转折**：旧人类后期用科技**屏蔽情感** → 后续残响几乎无威力 → 扩张派**断供**
- **认知污染**：残响武器电波干扰意识的效果；旧人类残响电波过强，连持有者都中招

### 其他宇宙势力

- 收割者联盟 / 静默议会 / 深空游牧者 → 见 [aliens.md](aliens.md)
