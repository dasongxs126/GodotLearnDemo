# 策划案工程

按 `game-design` MCP 的技能划分目录，技能产出落在这里：

| 目录 | 对应技能 | 内容 |
| --- | --- | --- |
| [`game-narrative/`](game-narrative/) | `game-narrative-design` | 剧情大纲、任务文本、对白、节奏与一致性校验 |
| [`game-system/`](game-system/) | `game-system-design` / `game-combat-design` / `game-level-design` | 玩法循环、战斗、关卡、原型规格 |
| [`game-art/`](game-art/) | `game-art-production` | 美术需求、规格与命名 |
| `GDD.md`（待生成） | `game-full-workflow` | 模块索引与跨模块一致性校验 |
| [`game-qa/`](game-qa/)（待建） | `game-qa-testing` | 测试用例与可玩性检查清单 |

## 约定

1. 本目录**只放策划案**。截图、概念图等二进制参考放 [`../screenshots/`](../screenshots/)；游戏内资产放 `assets/`。
2. 设定冲突以 [`../narrative/`](../narrative/) 为准，这里不新增世界观事实。
3. 文件名用小写 kebab-case；每个文档开头注明来源技能与对应的 story 实体 id。
