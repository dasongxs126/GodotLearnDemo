# 玩法原型设计（规格书）

> **标注**：**✅ 已定** ｜ **⏳ 待定**（有暂定默认值，可先做） ｜ **🚫 有意留白**（不在本阶段深入）

---

## 一、战斗规模与术语 ✅

- 玩家最多操作 **3 个角色**上场，执行 **3 V N** 战斗。

| 术语 | 含义 | 频率 |
| --- | --- | --- |
| **行动** | 单个角色的行动单位 | 队列中每个角色各一次 |
| **回合**（= 一轮） | 队列**所有人行动结束** | 整轮一次 |

---

## 二、回合与行动结构 ✅

```
本局开始
├ 硬币时间                       （每局一次）
└ 回合循环
    ├ 掷骰前（= 回合开始）→ 掷骰后 → 生成行动队列
    ├ 行动循环（按队列顺序，每个角色）
    │    ├ 行动开始前
    │    ├ 进攻链：进攻前 → 弹刀判定前 → 弹刀判定后 → 进攻后
    │    │      ─── 或 ───              （二选一，并列）
    │    ├ 防御链：防御前 → 防御后
    │    └ 行动结束
    └ 回合结束                     （队列走完）
```

- **硬币**：每局一次，定**先手 / 后手**。
- **掷骰**：每轮一次，在「掷骰前」执行。
- **回合结束** = 队列走完 = 一轮结束。

## 三、行动队列 ✅

### 骰子

- 面数 = **场上人物总和**（**最少 6 面**），数字 **1–N**。
- **特殊战斗可例外**：某 BOSS 使用 **4 面骰，所有面都是数字 9**。

### 排序优先级

1. 骰子数字：**大 → 小**
2. 数字相同：**先手 → 后手**
3. 同队且数字相同：**站位编号 小 → 大**

### 其他

- **站位编号**：**1 / 2 / 3**，敌我双方都有。
- **队列构成**：**敌我同列**。
- **可见性**：行动顺序与骰子结果**对玩家可见**。

### 指针

- 指针 = **当前操作人在队列中的位置**。
- 操作人位置被技能改变后，指针随之移动；其行动结束后，**从该位置向后推进**。
- 位于指针**之前**的角色**本轮不再行动**，**无补偿**。

**示例**

- `A B C E D F`，A 与 C 交换 → `C B A E D F` → 下一个是 **E**，随后 D、F。
- `A B C E D F`，A 令 B 与 E 交换 → `A E C B D F` → 下一个是 **E**，随后 C、B、D、F。

## 四、角色资源 ✅

- **开局 3 点，上限 5 点**；**溢出不再增长**。
- **角色私有**，不与其他角色共用。
- **不足 → 不能触发 / 不能释放**。

**回复途径**

| 情形 | 效果 |
| --- | --- |
| **防御** | 回血 + **回 1 点** |
| **我方当前进攻角色**弹刀成功 | **+1** |
| **敌人没有弹刀**（不对抗）时 | **我方进攻角色 +1** |

- **消耗**：0–5 点不等，属**技能设计** 🚫。

## 五、行动内容（二选一）✅

### A. 进攻 → 走进攻链

- 选攻击模组 → 选定敌人 → **弹刀结算**（见 §六）。
- **进攻链中间可主动触发技能**。
- 「进攻前 / 弹刀判定前 / 弹刀判定后 / 进攻后」是**连携窗口期**，队友、敌人若有响应技能，可在此响应释放。

### B. 防御 → 走防御链

- **回血 + 回资源点**。
- **没有弹刀阶段**。
- **防御链中间可主动触发技能**。
- 「防御前 / 防御后」是**连携窗口期**，队友、敌人若有响应技能，可在此响应释放。
- 例：队友技能「**任意队友防御后，消耗一资源点为其治疗**」→ 当前角色选择防御后即可连携。

### 技能的两种触发方式 ✅

**进攻链与防御链都适用**：

1. **正常触发**：在自己的行动中主动释放。
   > 例：A 的技能是「**选择防御后，可消耗 2 资源点额外恢复血量**」。表现为：**A 选择防御 → A 选择技能 → A 触发技能**。
2. **连携触发**：在连携窗口响应（见 §七）。

## 六、弹刀结算 ✅（数值 🚫）

底层机制 = **剪刀石头布**（三系互克）。

**模组**：攻击模组 **3 个** / 对抗模组 **3 个** + **不对抗** ⏳

> 正式名待结合世界观确定；原型与本文暂用机制名 **石头 / 剪刀 / 布**（玩家本来就懂这三个名字，不需要额外学习）。

### 我进攻

1. 选一个**攻击模组**
2. 选定敌人
3. 敌人**等概率随机**给出一个**对抗模组** ⏳
4. 判定 **胜 / 负 / 平** → 结算

### 我防守

1. 敌人攻击、**快要打到玩家时**
2. 我**输入一个对抗模组**
3. 判定 **胜 / 负 / 平** → 结算
4. **不按 = 不对抗 = 对方攻击成功**

**窗口不用倒计时表示** ✅：反应窗口的长度**就是敌人这次攻击的演出时长**——攻击动作飞过来的过程有多长，玩家就有多久可以输入。**反应慢了没按出来，等同于不对抗**。

> 由此推论：**演出时长即难度旋钮**。攻击动画越慢，玩家越容易弹刀；要做"快刀"，就让演出更短。正式时长 ⏳。

### 结果

| 判定 | 结果 |
| --- | --- |
| **成功** | 有伤害 |
| **平局** | 无伤 |
| **失败** | **弹刀失败方受伤** |

- 伤害模型与疗愈数值 🚫。

### 归属与阶段定义

- 弹刀**只出现在「进攻链」**：我进攻 → 敌人弹刀；别人攻击我 → **我弹刀**。
- **「攻击弹刀判定前 / 后」以「结算弹刀结果」为分界**：结算**前** = 弹刀判定前，结算**后** = 弹刀判定后。

## 七、阶段连携（核心玩法）✅

- **连携阶段 = 技能释放窗口**。
- **开启条件**：**场上有存在触发技能的可能时**，就开启子弹时间。

### 手动模式

- 子弹时间 = **慢放**（演出效果，给玩家反应时间）。
- **n 秒可配置，配成固定值**；做成**可插拔**，方便技能设计。
- **超过子弹时间 → 连携不触发**。
- 多个连携可同时响应，**按玩家手动顺序执行**（可选 A / B / A+B）。
- **可见性**：可见「某技能可触发」；**不显示**具体效果与代价。

### 自动模式

- 每个技能有**优先级编号**（**配置表配 + 代码设置，互不相同**）。
- 自动按编号执行。
- **模式切换为全局设置**。

### 规则

- **允许嵌套连携，不设深度上限**。
- **代价**：必然消耗资源；**资源在技能成功释放后扣**。
- **资源不足 → 不能触发**。
- **15 个阶段是否全为连携阶段**：⏳ 暂定为是。

**示例**

> A 技能是「**攻击成功后可触发**」；B 攻击成功 → **子弹时间** → A 成功发动技能造成伤害 → C 技能是「**任意技能造成伤害后可触发**」→ A 技能成功后**开启子弹时间**，等 C 是否连携。

## 八、阶段清单 ⏳（暂定 15 个）

**A. 回合管线阶段**（有序，进管线）

| 序 | 阶段 | 频率 | 归属 |
| --- | --- | --- | --- |
| 1 | 投掷骰子前（**= 回合开始**） | 整轮一次 | 轮次级 |
| 2 | 投掷骰子后 | 整轮一次 | 轮次级 |
| 3 | 行动开始前 | 每个角色 | 行动级 |
| 4 | 进攻前 | 每个角色 | **进攻链** |
| 5 | 攻击弹刀判定前 | 每个角色 | **进攻链** |
| 6 | 攻击弹刀判定后 | 每个角色 | **进攻链** |
| 7 | 进攻后 | 每个角色 | **进攻链** |
| 8 | 防御前 | 每个角色 | **防御链** |
| 9 | 防御后 | 每个角色 | **防御链** |
| 10 | 行动结束 | 每个角色 | 行动级 |
| 11 | **回合结束** | 整轮一次 | 轮次级 |

**B. 任意时刻窗口**（**不纳入回合管线**）

| 序 | 阶段 | 说明 |
| --- | --- | --- |
| 12 | 技能生效前 | **每个技能各一个**窗口 |
| 13 | 技能生效后 | **每个技能各一个**窗口 |
| 14 | 资源点变动 | 任意时刻 |
| 15 | 行动序列变动 | 任意时刻 |

- **技能生效窗口与管线的关系**：**叠加**（管线走到某阶段时，同时检查技能窗口）。

## 九、技能影响行动队列 ✅

- **本质就是操作行动顺序**（提前 / 延后 / 交换 / 移除 / 反转…）。具体属**技能设计** 🚫。
- **代价**：**必然消耗资源点**，不够就放不了；**只靠资源点限制**，**无冷却、无每场次数限制**。

---

## 十、模组设计 ⏳

- **模组名称与具体三系**：**不在玩法验证阶段起名**，结合世界观设计（很可能与异力 / 术法 / 科学三套体系挂钩）。
- **暂定默认**：**剪刀石头布**三系互克。
- **敌人随机**：**等概率**。

## 附录：原始口述记录（批次 1–20）

### 批次 1

- 玩家操作**最多 3 个角色**上场，执行 **3VN** 的战斗。
- 开局需要**抛硬币机制**决定**先手**和**后手**。
- 需要**最少 6 面骰**；**全场角色每个轮次**根据骰子数字决定行动顺序。
- 排序：① 数字**大**在前、**小**在后；② 数字相同则**先手**在前、**后手**在后；③ 同队伍则按**站位编号**，**小**在前、**大**在后。

### 批次 2

- **每轮战斗开始后**都要执行一次**重新投掷**。
- **每轮结束后**会根据**新的投掷结果**更换行动顺序。

### 批次 3

- 角色资源：**五个能量点**，**开局 3 能量点**，**技能需要消耗能量点**。
- 角色普攻：进攻有**三种攻击方式**；进攻时可以在**进攻瞬间选择一种执行「弹刀」**；根据结果决定本次是否造成有效伤害；**类剪刀石头布**；**对拼成功有伤害、平局无伤、失败反伤**。
- **此处遗留**：可能是成功增伤、平局普伤、失败无伤——数值问题。

### 批次 4

- 自己的回合可以选择**不攻击**，进行**疗愈**，恢复一定生命值，**资源点 +1**。

### 批次 5

- 技能除**常规攻击性、防御性技能**外，可以**影响由骰子组成的行动队列**，例如**交换队列上两个人的顺序**。
- **行动队列是单指针移动，跟随当前操作人**。
- 举例：队列 `ABCDEF`，当前行动人 `A`，技能让自己和 `F` 交换 → 交换后 `FBCDEA`，且**行动指针在 A**，即 `BCDEF` 的回合**全部跳过**，执行**下一轮摇骰定行动次序**。

### 批次 6

- **核心玩法：阶段连携**。技能在任意阶段可能发生**连携事件**触发技能。
- 例：某人物技能是——**队友拼刀成功后，消耗一资源点执行追加攻击**。
- 全部阶段：① 投掷骰子前 ② 投掷骰子后 ③ 进攻前 ④ 进攻后 ⑤ 防御后 ⑥ 技能生效前 ⑦ 技能生效后 ⑧ 回合开始前 ⑨ 回合开始后 ⑩ 攻击弹刀判定前 ⑪ 攻击弹刀判定后 ⑫ 资源点变动 ⑬ 心动序列变动。
- 其他可能存在、没想到的场景，遇到再补。

### 批次 7

- 连携触发时，如为**手动模式**，执行**子弹时间**，在 **n 秒内**需响应对应连携；**如错过，则认为不触发**。**多个连携可同时响应**，按照**用户手动顺序执行**。例：攻击成功后队友 A、B 都有连携，子弹时间内用户可以自行选择 **A / B / A+B**。
- **自动模式**下，每个技能存在**优先级编号**，自动按照编号执行。

### 批次 8（阶段时序）

```
本局开始
├ 硬币时间
│    └ 一轮开始
│        └ 掷骰前 → 掷骰后 → 生成行动队列
│        └ 角色
│                └ 回合开始前
│                        └ 进攻前 → 弹刀判定前 → 弹刀判定后 → 进攻后
│                        └ 防御前 → 防御后
│                └ 回合结束
```

- **行动序列变更**、**资源点变动**：**在任意时刻都有可能触发**。

### 批次 9

1. 「防御前」是**漏了**。
2. **没有「回合开始后」**；「技能生效窗口」可以**任意时刻触发**，所以**无法纳入回合管线**。
3. 统一定义：**队列所有人行动结束 = 回合结束 = 一轮结束**。**属于可连携阶段**。
4. **连携阶段 = 技能释放窗口**。每个连携阶段，如果有角色有相应技能，**都进入子弹时间**，等待玩家响应。

### 批次 10

1. 单个角色的行动单位**叫「行动」**；原来的「回合开始前」和「回合结束」改为「**行动开始前**」「**行动结束**」。
2. 原时间管线里的**改了名**：行动开始前和行动结束**触发一次**。**回合开始前和回合结束也是一次**。

### 批次 11

1. 「回合开始前 / 回合结束」**其实就是掷骰那一步，不额外算**。
2. **防御和进攻是二选一，所以是并列的。**

### 批次 12

- **「掷骰前」= 回合开始**；**「掷骰后」不是回合结束**。

### 批次 13（弹刀结算）

- **我是玩家进攻方**：选择一个**攻击模组** → 选定敌人 → 敌人**自动随机**给出一个**对抗模组** → 判定胜负平后结算。
- **我是玩家防守方**：敌人攻击后**快要打到我时**，我可以**输入一个对抗模组** → 判定胜负平后结算。这个过程就是**真实参考动作游戏弹刀**。
- 也允许**反应不过来没输入，那就是失败**。
- 敌人的随机对抗模组**要有「不对抗」这个，是四选一**。

### 批次 14

- 实际上**底层就是剪刀石头布**。
- **攻击和防御使用同一个模组描述有点不好设计**。
- **「不对抗」就是不出，攻击成功。**

### 批次 15（防御链）

- 玩家选择**防御**：**回血回资源点**，**没有弹刀阶段了**。
- **只有我攻击才会设计弹刀**；但是**我在别人的回合成为目标时，还是可以正常弹刀的**。
- **防御前 / 防御后主要是连携窗口期**。
- 举例：队友技能「**在任意队友防御后，可消耗一资源点为他治疗**」，那么就在我当前操作角色选择防御后可连携。

### 批次 16（资源系统）

1. 「能量点」和「资源点」**是一个东西**。
2. **开局 3，上限 5**。
3. 回复途径：**拼刀成功**、**或敌人没有拼刀**恢复 1；**我作为目标拼刀成功**也恢复 1。
4. 具体消耗属于**技能设计**，**0–5 都有可能**，**不在本轮深入**。

### 批次 17（连携嵌套与资源）

1. **允许嵌套连携**。连携都是技能，**一定会花费资源**，且**有子弹时间需要玩家操作**，**不一定 100% 成功**，所以**不用考虑深度**。
2. **不够就不能触发**。且**资源点是绑定人物的，不是全队共用资源**。

### 批次 18（模组体系）

1. **模组名不想在玩法验证阶段起**，这还涉及**世界观建设**，理论上应该**结合世界观做**。可以**暂时按剪刀石头布**来。
2. 敌人随机**似乎都可以**，可能要等**玩法跑起来后实际体验**，**可以先按等概率做**。

### 批次 19（队列操纵）

1. **必然消耗资源点**，不够就放不了，所以**相当于只靠资源点限制就够了**。
2. 这属于**具体技能设计**，没必要在这个阶段讨论，**本质就是操作行动顺序，能列出来的都有可能**。
3. 指针语义示例：
   - 「ABCEDF，当前是 A，如果是 **A 和 C 换**，那么序列变成 **CBAEDF**，下一个是 **E** 行动，随后是 D F。」
   - 「如果是 **A 让 B 和 E 交换**，顺序变成 **AECDBF**，那么下一个是 **E**，顺序是 **ECDFB**。」

### 批次 20（参数清单）

1. 骰子**最少 6**，数字 **1–N**。**面数为场上人物总和**，或特殊战斗有特殊情况。例：某 BOSS 是 **4 面骰且都是数字 9**。
2. **123 即可**，**敌人也有**，方便代码计算顺序。
3. **可见**。
4. **敌我同列**。
5. **没有**。
6. 可以理解为**拼刀失败方受伤**，**不要使用「反伤」**。
7. **数值问题，暂不考虑**。
8. **我方当前进攻的角色**。
9. **我方进攻角色**。
10. **是的**。
